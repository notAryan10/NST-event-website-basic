<h1>🎉 Campus Event Calendar & RSVP
A React-based event listing platform for Newton School of Technology that helps students stay updated with upcoming events, workshops, competitions, club meetings, and social drives.</h1>

✨ Features
🗓️ View upcoming and past events

🔍 Filter events by category (Masterclass, Competitions, Workshops, etc.)

📆 Sort by upcoming or past events

➕ Submit new events (with preview)

💬 Cool and user-friendly UI/UX

📚 Dummy data powered basic version (future upgrade to admin approval, RSVP system, and backend)

🚀 Technologies Used
React.js

Tailwind CSS (for styling)

React Router

Dummy JSON data (for now)

(Future: Firebase backend)

📦 How to Run Locally
bash
Copy
Edit
git clone <your-repo-url>
cd campus-event-calendar
npm install
npm run dev
Then open: http://localhost:5173
